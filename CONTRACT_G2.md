# Контракт этапа G2 — полная версия (дополняет ARCH.md и CONTRACT_G1.md)

Цель: полноценный матч «Bed Wars на архипелаге» в реалистичной графике The Forest: 4 команды (ты + 3 бота или 2×2), флаг и возрождение, мосты из связок брёвен через море с акулами, невосстанавливаемый мир, выживание (вода, еда, огород, мусорный берег), тропическая фауна и приручение, бой. Матч 3–4 часа. Победа — последний флаг. Всё по-русски. Модули подключаются через `scripts/world/match.gd` (список MODULES) — сцена модуля `scenes/<модуль>/<модуль>.tscn` или скрипт `scripts/<модуль>/<модуль>.gd`.

## Волна 1 (параллельно)
### WORLD (scripts/world, кроме flora)
- Полный архипелаг 20–30 островов (`islands()` с `kind`: home×4 (команды 0–3, по кругу), center (вулкан, самый большой), shared×4 (общие), spring (пресное озеро/ручей), swamp (мангры), rocky (утёсы), atoll (песчаный), wreck (кладбище кораблей)); проливы 40–110 м между соседями; отмели, рифы, островки. Пресная вода: `fresh_water_at(pos: Vector3) -> bool` (только spring и редкие родники), `springs() -> Array[Vector3]`. Точки: `trash_beaches()`, `turtle_beaches()`, `swamps()` → Array[Dictionary]{pos, radius}. Производительность на большой карте: стриминг/LOD чанков, дальность, отсечение.
### FLORA (scripts/world/flora)
- Растительность по биомам на всём архипелаге (джунгли, пальмовые пляжи, мангры, болота, скалы); новые узлы-ресурсы: лианы (`liana` → `fiber`/`rope`), лечебные травы (`herb`), дикие культуры с семенами (`wild_taro/maize/melon` → `seed_*` + еда), ягодные кусты (`berries`, шанс `seed_berry`), хлопок (`cotton`), железная руда и сера в скалах (`iron_ore`, `sulfur` — редко), кокосы; всё невосстанавливаемо. API: `Flora.instance().nodes_near(pos, r, kind)`.
### FAUNA (scripts/fauna — новая папка)
- Реалистичные процедурные животные (как акулы у SEA): кабан, краб, змея (яд), крокодил (болота/устья, засада у воды), обезьяна (ворует из сундуков/с земли), игуана/варан, скорпион, паук, попугаи и птицы (стаи), летучие мыши (ночью), черепахи (яйца на пляжах). ИИ, анимация (процедурная кость/изгиб), звуки. Яд: у персонажа `poison: float` (урон/с) и `poison_time: float`; снимается травами (SURVIVAL). Приручение: кормить (ПКМ едой) → приручён (следует/стоит), разведение двух прирученных + корм → детёныш. Группа `animals`, `apply_damage`, дроп (`meat_raw`, `hide`, `crab_meat`, `turtle_egg`). API: `Fauna.instance().animals_near(pos, r)`, `tame(...)`.
### SURVIVAL (scripts/survival — новая папка)
- Голод/жажда (скорость под 3–4 ч матча), пресная/морская вода (морская: жажда хуже + урон), тара (бутылка, скорлупа кокоса), кипячение в котелке на костре, солнечный опреснитель, дождевая бочка/тент (`world.weather()`, `rain_factor`), кокосы, порча еды (свежесть в слоте), копчение, костёр (готовка), огород (грядка, семена, полив, урожай — единственная возобновляемая еда), травы (припарка снимает яд), мусорный берег (обломки после штормов: бочки, сети, бутылки, металлолом → переработка), рецепты. Структуры — через BUILD API `BuildModule.instance().register_def(...)` если есть, иначе свои узлы с `interact`. API ботам: `Survival.instance().drink_sources(pos)`, `food_sources(pos)`.
### COMBAT (scripts/combat — новая папка)
- Оружие: копьё (бросок), дубина, топоры, лук + стрелы (+огненные), арбалет, мушкет, пистолет (реалистичная отдача/разброс/перезарядка), коктейль Молотова (поджигает деревянные мосты и постройки — ключевая фишка), динамит. Снаряды с физикой, зоны попадания (голова ×2, ноги ×0.75), урон постройкам (`apply_damage(..., 'fire'|'explosion')`, `ignite()`), прицел (ПКМ), блок. Модели оружия реалистичные (assets + процедурно). API: `Combat.fire(shooter, weapon_id, origin, dir) -> bool`, `Combat.melee(attacker, weapon_id)`, `Combat.throw_item(thrower, id, origin, dir, power)`, `Combat.WEAPONS`. Игрок вызывает их из своего кода (правка player — только точечно, через существующие хуки `use_selected`/on attack).

## Волна 2 (после волны 1)
BOTS (навигация, добыча, стройка, мосты, атака флагов), GAME/UI (лобби, 4 команды, правила матча, победа, HUD флагов, мини-карта, статистика), BUILD+ (оборона, сундуки, верстак, территория флага, люки/ворота на мостах), SEA+ (рифы-кораллы, укус ~10 с, приманка).

## Правила
- Каждый — в своей папке; `scripts/core`, `project.godot`, `scripts/player` — только точечные правки с описанием в отчёте (координатор сведёт).
- Тесты медленные (llvmpipe, 2 ядра): делай мало, но осмысленных тестов; `TEST_TIMEOUT=1500`. Скриншоты — посмотри и доведи вид.
