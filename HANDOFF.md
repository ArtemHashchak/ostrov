# Передача работы между сессиями — «Острова» (Godot 4.7.2)

Этот файл — для новой сессии Claude, которая продолжает разработку. Читать первым, затем ARCH.md, CONTRACT_G1.md, CONTRACT_G2.md, ASSETS.md.

## Что это
Игра «Острова»: Bed Wars на тропическом архипелаге в реалистичной графике в духе The Forest (вид от первого лица). 4 команды (игрок + 3 бота, или 2×2), у каждой флаг: пока флаг цел — возрождаешься. Мосты из плавучих связок брёвен через море с акулами — главная механика. Мир невосстанавливаемый (срубленное дерево оставляет пень навсегда). Выживание: пресная вода в дефиците, порча еды, огород, мусорный берег. Тропическая фауна с приручением. Матч 3–4 часа. Победа — последний флаг. Язык интерфейса — русский. Платформа — ПК (Windows/Mac), рендер Forward+.

## Решения пользователя (кратко)
- Реалистичная графика как The Forest; движок Godot 4; ПК. Концепт — острова + Bed Wars, не сюжетный клон.
- Сохраняем из веб-прототипа: флаг и возрождение, мосты через море, акулы и живое море, архипелаг, боты-соперники, невосстанавливаемый мир, вода/огород/мусорный берег, тропическая фауна и приручение. Эпохи — нет. Враждебных племён — нет.
- Мосты проще: связки брёвен на воде.
- Ассеты — бесплатные с GitHub (см. ASSETS.md; polyhaven/ambientcg из среды недоступны).
- Пользователь хочет получить ПОЛНУЮ версию (сборки Windows и Mac) только после полной готовности.
- Веб-прототип (Three.js) остаётся как справочник механик: опубликован как артефакт «Острова — v0.3».

## Окружение
