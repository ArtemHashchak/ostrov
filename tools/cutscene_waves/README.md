# Снимок генератора волн для кат-сцен

Копия океана игры на 19.11.2026 (коммит c012a36). Пользователю понравилось, как это выглядит **сверху, особенно в грозу**, поэтому версия сохранена отдельно. Игровой океан (`scripts/world/ocean.gd`) дальше меняется под вид «с ног» у пляжа, а этот снимок — нет.

## Что внутри
| Файл | Что это |
|---|---|
| `cutscene_ocean.gd` | класс `CutsceneOcean`: сетка за камерой, 8 волн Герстнера (зыбь + ветровые), сеты, плавная погода, шторм, брызги с гребней, `wave_height()` |
| `cutscene_ocean.gdshader` | шейдер воды: цвет по глубине, FFT-рябь, барашки-гребни, полосы пены, прибой, рябь от дождя, вид снизу |
| `fft_atlas.png`, `fft_meta.gd/.json` | запечённая зацикленная FFT-рябь (64 кадра, 8 с, плитка 24 м) |
| `bake_ocean_fft.py` | генератор FFT-атласа (numpy) — перезапекать при желании |
| `textures/` | карты нормалей и текстура пены |
| `cutscene_storm_demo.tscn/.gd` | демо: камера на высоте ~85 м облетает штормовое море с островами, ливень, молнии |

## Как использовать в кат-сцене
```gdscript
var ocean := CutsceneOcean.new()
add_child(ocean)
ocean.build(func(x, z): return height_at(x, z), Rect2(-700, -700, 1400, 1400))  # рельеф для глубин/пены
# каждый кадр:
ocean.set_weather_drive(Vector2(1, 0.35), 26.0, 1.0, 1.0)   # ветер, м/с, шторм 0..1, дождь 0..1
ocean.update(delta, camera.global_position, 0.0, 3.0)       # уровень воды, множитель волн
```
- Качество: `ocean.cutscene_quality = 3` до `build()` (по умолчанию «ультра»).
- Ночь: `ocean.set_night_tint(Color(0.5, 0.56, 0.72))`.
- Демо: открыть `cutscene_storm_demo.tscn`, F6. В инспекторе — шторм, ветер, высота/радиус/скорость облёта, ночь, молнии.

## Важно
- Папка `tools/*` исключена из экспорта игры (`export_presets.cfg`). Чтобы использовать снимок в собранной игре, перенесите папку, например, в `scenes/cutscenes/waves/` и поправьте пути `res://` в `cutscene_ocean.gd`.
- Не правьте эти файлы ради игрового океана — для этого есть `scripts/world/ocean.gd`.
