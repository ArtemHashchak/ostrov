# Краб из пака пользователя: crab.blend → GLB со скелетом

Скрипты Blender (pip `bpy`, Blender 5.3), запускать `python3 -I <скрипт>`; автозапуск скриптов из .blend выключен
(`use_scripts=False`). Пути — во временной папке /tmp/crabwork, исходник /tmp/models_in/crab/crab.blend.

1. `inspect.py`, `inspect2.py` — что внутри: меш 130k (multires) / 32.5k базовый, арматура автора «CAngrejo» 34 кости
   (клешня + 3 ходильные ноги на сторону, по 4 кости), UDIM-текстуры 4096 (одна плитка 1001), UV для текстур — `automap`.
2. `stageA.py` — сцена очищена, поза сброшена в покой, модификаторы multires/subsurf/displace сняты, лишняя кость Bone.006 удалена.
3. `stageA2.py` — поиск двух «пальцев» клешни: графовое расстояние от ладони (.003) по рёбрам меша, порог, при котором
   кончик клешни распадается на две компоненты.
4. `stageB2.py <0|1>` — подвижный палец (0 — длинный изогнутый нижний) → группа и кость R/L.Finger (дочь .004),
   кость-метка R/L.FixTip на кончике неподвижного пальца (для оси шарнира). `renderB.py` — проверочный рендер.
5. `bake.py` — запекание итогового цвета из нодового материала автора (тонировка, шум) в 1024 по `automap`.
6. `stageC.py` — децимация 32.5k → 7.0k (с симметрией по X, веса сохраняются), масштаб: ширина панциря 0.30 м,
   стопы на нуле, экспорт GLB (скин, без анимаций). Текстуры 4096 → 1024, ORM = AO/Roughness/Metal.
7. `bonesjson.py` — голова/хвост костей (Godot: x, z, −y) → scripts/fauna/user_crab_data.gd.

Анимация — процедурная в игре: scripts/fauna/user_crab_rig.gd (UserCrabRig, наследник ArthropodRig).
